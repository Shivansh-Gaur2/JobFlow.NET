# Support

Use GitHub Discussions for usage questions, design conversations, and ideas that are not confirmed bugs.

Use GitHub Issues for reproducible defects and clearly scoped feature requests. Read [CONTRIBUTING.md](CONTRIBUTING.md) first, and do not disclose vulnerabilities in public issues; use the process in [SECURITY.md](SECURITY.md).

JobFlow.NET is currently an experimental learning project, so support is best-effort and no response-time commitment is made.
