# Security Policy

## Supported versions

JobFlow.NET has not released a stable version. Security fixes, if any, are applied to the current `main` branch only.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues.

Once this repository is hosted on GitHub, use GitHub's private vulnerability reporting feature from the repository's **Security** tab. Include:

- A clear description of the issue and its impact.
- Reproduction steps or a minimal proof of concept.
- Affected version or commit, environment, and configuration details.
- Any suggested mitigation, if known.

If private reporting has not yet been enabled, do not disclose sensitive details publicly. Contact the repository owner through their GitHub profile and ask for a private reporting channel.

## Response expectations

Reports are handled on a best-effort basis. Acknowledgement, triage, remediation, and disclosure timelines depend on the severity and reproducibility of the report.
